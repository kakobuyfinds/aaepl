Buyer guides

Compare size charts before you order

If you came for a TigBuy shoes spreadsheet, start with a sneaker size chart and check whether its centimeter figure is foot length or insole length. Compare like for like with a pair you own. For clothing, record hoodie chest width and sleeve length, T-shirt shoulder width, jacket layering room, pants waist and inseam, or jersey body length. Ask for cap circumference if the listing gives only an adjustable size.

Use warehouse photos to inspect the item

When comparing TigBuy finds, record the marketplace item ID, selected color and seller SKU. When TigBuy QC photos or other warehouse images are available, match the variant first. For shoes, request outsole tread, toe-box and heel photos. For a bag, ask for zipper and handle close-ups. For jewelry, check the clasp and finish. Ask for a ruler photo if the fit depends on a measurement, and check the return deadline before approving dispatch.

TigBuy shipping guide for comparing quotes

Start with the item subtotal, domestic delivery and any agent or payment fees. Use packed parcel dimensions to compare actual weight with dimensional weight. If you are considering parcel consolidation, compare one combined quote with the cost of separate parcels and check the carrier’s restrictions. For the US, UK or EU, check the quote for your delivery address, currency, tracking, and how import charges are handled.

Frequently asked questions

What is a TigBuy spreadsheet?

A TigBuy spreadsheet is a directory used to shortlist and compare marketplace product links. This guide links to Hipobuyfind categories and explains what to verify before buying.

How do I check a Weidian or Taobao product link?

Open the original listing and confirm the seller, the selected variant and whether that exact size and color can still be ordered.

Can warehouse QC photos prove authenticity?

Warehouse photos can show visible condition, labels and measurements. For authenticity, look for verifiable seller provenance and purchase documentation.

How do I estimate international parcel shipping?

Use the destination, packed dimensions and actual weight to request a carrier quote. Check which weight the carrier bills and which charges the quote includes.
